# Sistema_de_control_de_riego_y_sensores_IoT_para_cultivos_de_palm
Es una plataforma de agricultura de precisión para plantaciones de palma de la zona de Mutatá. Resuelve el monitoreo ineficiente de humedad y variables climáticas en grandes extensiones de tierra: nodos sensores IoT distribuidos en el cultivo miden humedad, temperatura del suelo y precipitación.
